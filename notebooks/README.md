# Notebooks

This folder contains the analysis notebook for the Diabetes Prediction: Regularized Logistic Regression project.

- `diabetes_logistic_regression.ipynb` — trains and evaluates custom and scikit-learn logistic-regression models, compares regularization approaches, and reports final model performance on a held-out test set.

Run the notebook from top to bottom after following the data-access instructions in [`../data/README.md`](../data/README.md).
